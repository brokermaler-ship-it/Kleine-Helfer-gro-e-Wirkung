# Vorlage: Kundenprofil und Auftragsblatt (Entwurf)

Gehört zu: `2026-11-16-kundenorientierte-auftragsuebergabe-design.md`
Grundregel: Kurz halten. Ein Blatt, höchstens eine Seite. Nur ausfüllen, was für Planung und Kundeninformation gebraucht wird.

---

## Teil 1: Kundenprofil (einmal je Kunde, bei Änderungen aktualisieren)

| Feld | Eintrag |
| :--- | :--- |
| Kunde | |
| Verantwortlich im Vertrieb / Stellvertretung | |
| Was transportieren wir, und wofür braucht der Kunde es? | z. B. Container für Schiffsabfahrt, Getreide zum Hafen, Autoteile für Produktionstakt, Kohle fürs Kraftwerk |
| Woran erkennt der Kunde „das war gute Arbeit“? | z. B. Ankunft vor Schiffsschluss, Zug auf Fenster pünktlich, keine Unterbrechung der Produktion |
| Was ist für den Kunden ein Problem, auch wenn es vertraglich erlaubt ist? | z. B. Verspätung über 2 Stunden, späte Info am Wochenende |
| Wiederkehrende Slots / Zeitfenster (nicht verhandelbar) | z. B. Schiffsschluss jeden Dienstag 18:00, Anlieferfenster Kraftwerk 06:00 bis 10:00 |
| Ansprechpartner beim Kunden (Disposition, Notfall) | |
| Bevorzugter Informationsweg und -zeitpunkt | Telefon / Mail / Portal; bei Verspätung ab wann |
| Vertragliche Besonderheiten (Pönalen, Sonderregeln) | Verweis auf Vertrag |
| Letzte Aktualisierung / durch wen | |

| Feld | Eintrag |
| :--- | :--- |

## Übergabe-Check (Vertrieb, vor Weitergabe)

- [ ] Profil des Kunden ist aktuell
- [ ] Alle Zusagen aus Mails und Telefonaten stehen im Auftragsblatt
- [ ] Wichtige Slots / Termine sind eingetragen
- [ ] Informationsverantwortlicher gegenüber dem Kunden ist benannt
- [ ] Blatt liegt an der Angebotsnummer in LP one

Die Verkehrsplanung bestätigt den Eingang und meldet Rückfragen innerhalb eines Arbeitstags an den Vertrieb.

---

## Hinweise für den Pilot

- Ablage in LP one (Anhang oder Notizfeld) ist noch nicht geprüft.
- Pflichtfelder bewusst klein halten; nach dem Pilot prüfen, welche Felder tatsächlich genutzt werden.
- Messen: Rückfragen der Planung an den Vertrieb, vermeidbare Leerfahrten, Beschwerden zur Information.

## Worum geht es?

Sie nehmen freiwillig an einem Test teil. Wir wollen herausfinden, ob Sie Inhalte besser
behalten, wenn Sie sie im Gespräch mit einem **KI-Tutor** lernen. Der Tutor ist ein
Computerprogramm, kein Mensch. Er stützt sich auf eine freigegebene Arbeitsanweisung. Im
Zweifel gilt die Arbeitsanweisung selbst.

**Bewertet wird das Lernformat, nicht Sie.** Ihre Ergebnisse werden nicht an Ihre
Führungskraft oder die Personalabteilung weitergegeben und nicht für Beurteilungen genutzt.
Das ist in einer Betriebsvereinbarung mit dem Betriebsrat geregelt.
